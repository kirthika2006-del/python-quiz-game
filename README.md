# Python Quiz Game

## About the Project

This is a simple text-based quiz game developed using Python.

The game asks the user five multiple-choice questions based on basic Python concepts. The user has to choose the correct answer from A, B, C, or D.

The program checks the answers and calculates the final score and percentage.

## Features

- Five Python multiple-choice questions
- Random question order
- Answer validation
- Score tracking
- Final percentage calculation
- Performance message
- Play again option

## Technologies Used

- Python
- Random Module

## Python Concepts Used

- Variables
- Lists
- Dictionaries
- Functions
- If-Else conditions
- For loop
- While loop
- User input
